# docs/archive の役割

このフォルダは、過去資料・完了済み計画・旧前提の調査資料を保存する場所です。

## 主な分類

- `research/`: root直下にあった `deep-research*.md` の退避先
- `presentation/`: 旧説明PPTXの退避先
- `user-settings/`: Supabase SQLメモなど、ユーザー設定用メモの退避先
- 直下のMarkdown: 過去の実装指示、完了済みロードマップ、作業ログ

## 扱い

- 現在仕様の正本ではありません。
- 削除せず、履歴確認と判断の補助として残します。
- 実装に使う場合は、`docs/00_PROJECT_CORE.md`〜`docs/06_OPEN_ISSUES.md` と照合します。
- 過去ログ内の旧パスは、当時の記録として残します。
