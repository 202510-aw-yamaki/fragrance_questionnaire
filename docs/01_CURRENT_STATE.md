- 会員登録のDB接続が未完了。
- 会員ページからアンケート経由で再予約した場合、前回完成品との差分を見せる作りになっていない。
- 会員ID・パスワード・メールアドレス・アンケート結果・制作履歴の紐づけがまだ弱い。

2026-04-29追記:
会員ログインページは Supabase Auth signUp / signIn と `customers.auth_user_id` 作成に接続した。
ただし、会員本人の制作履歴表示、過去完成品との比較、アンケート結果・予約・制作履歴の完全な紐づけは未完了のため、上記課題は「DB接続の入口は実装済み、会員ページ整理は継続」として扱う。

2026-04-29追記:
ログイン済み会員の `customers.id` を、アンケート結果・予約・完成品へ紐づける土台を追加した。
ただし、会員ページ上での制作履歴表示、過去完成品との差分表示、過去完成品を起点にした再予約UIは後続フェーズとして扱う。

### 商品・QR導線

- QR商品価格を管理者画面で設定する機能がない。
- QRコードと完成品データの紐づけ方が曖昧なままだと将来的なアキレス腱になる。

- `staff-customer-detail.html` に商品名入力欄がない。

- QR発行条件が明確に実装されていない。

2026-04-29追記:

QR発行条件、QR依頼対応、発送先入力、発送完了、通知対応済み操作は後続フェーズとして扱う。

### 認証・権限

- スタッフの自動ログインが有効なため、管理者がスタッフとしてログインするには一度ログアウトが必要。
- 管理者・スタッフ・会員の権限分離が十分ではない。
- UI上だけでなくDB側でも権限を分ける必要がある。

## 実装時の注意

- 既存画面は可能な範囲で活かす。
- ただし、DB・認証・QRコード関連の曖昧な構造は放置しない。
- 見た目だけを整える実装を優先しない。
- 既存のQR関連処理がある場合は、流用前に必ず設計方針と照合する。
