# UNMET_REQUIREMENTS

本書は、追加要望に対して現時点で未達の要件だけを記載する文書です。  
達成できた項目は `COMPLETED_REQUIREMENTS.md` へ移行します。

## 管理権限の分離

- `staff` と `manager` の権限を分離する
- スタッフ画面と店舗管理者画面のログイン後導線を権限別に分ける
- 店舗管理者がスタッフ登録権限を付与 / 編集できるようにする

## 店舗管理者側のマスタ管理

- 基剤専用の登録 / 編集画面を用意する
- 原料専用の登録 / 編集画面を用意する
- 基剤 / 原料それぞれに対してロット、商品種、テンプレート種類を管理できるようにする
- 基剤 / 原料それぞれの五軸寄与値をスピンボタンで微調整できるようにする
- `material_points` に `material_type = base | ingredient` を持たせ、共通マスタとして整理する

## データモデル拡張

- 顧客を継続管理するための `customer_id` を導入する
- 顧客 ID に対して予約情報、アンケート結果、接客履歴、レシピ履歴を紐づける
- 再注文を前提に、過去レシピと最終五軸を再参照できるようにする

## 再注文とテンプレート反映

- 再注文時に過去レシピを呼び出せるようにする
- 再注文時に過去の最終五軸と比較できるようにする
- 再注文実績が増えたレシピをフロント側おすすめテンプレートへ昇格できるようにする

## 運用補助

- `staff/staff-dashboard.html` と `admin/admin-dashboard.html` の役割差分が文書から直感的に分かるよう整理する
- 実データを使ったブラウザ確認手順を固定し、文書へ追記する
- Supabase 本番へ `workshop_sessions` を反映した後の確認フローを文書へ追記する
