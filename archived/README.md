# archived の役割

このフォルダは、現在の実装本体から外した旧HTML、旧CSS、旧JS、旧画像、プロトタイプを隔離する場所です。

## 主な分類

- `legacy/`: リニューアル後に退避した旧ページ・旧JS・旧画像
- `layout-rebuild-20260501/`: 2026-05-01 UI再構築時に退避した旧実装
- `prototypes/visual-prototype-20260504/`: レイアウト再現用の過去プロトタイプ

## 扱い

- 現在仕様・現在実装の参照元ではありません。
- 明示指示がない限り、ここからコードやUIを流用しません。
- 必要な場合は、現在の正本資料と照合し、過去実装として参考に留めます。
