# Visual Prototype

`レイアウトimg/` の各完成イメージを最終目的地として、既存HTMLとは別に画面再現を進めるための静的プロトタイプです。

## 方針

- 既存の `img/` と `レイアウトimg/` を相対パスで参照する
- ロゴは完全再現対象から外し、画面構成、余白、画像差し込み、色、密度を優先する
- 依存パッケージを増やさず、`visual-prototype/index.html` をブラウザで開くだけで確認できる状態にする
- 画面グループごとに小さくコミットする

## 起動

`visual-prototype/index.html` をブラウザで開いてください。

将来的に Next.js へ移す場合も、ここで作った画面データとデザイントークンを移植元として使います。
